# Weather App (Python)

A Python-based application that retrieves real-time weather information for a given city and stores the data in a CSV file for record-keeping and analysis.

## Key Features
- Retrieves live weather data using an API
- Displays temperature, humidity, and weather condition
- Persists data in a CSV file with append support

## Technologies
- Python
- Requests library
- CSV file handling
- DateTime module

## Usage
1. Install dependency:
   pip install requests
2. Run the application:
   python weather_app.py
3. Enter a city name when prompted

## Skills Demonstrated
- API integration
- JSON data parsing
- File handling in Python
