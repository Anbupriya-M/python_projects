# Python Projects

This repository contains Python projects developed as part of my learning journey,
focusing on practical application of Python concepts in real-world scenarios.

## Projects Included

### 1. Weather App

📁 Folder: `weather_project/` 

A Python-based application that collects real-time weather data using an external API.
The app accepts user input (city name) and stores the fetched weather information
into a CSV file for record keeping and further analysis.

**Key Concepts Used:**
- API integration
- User input handling
- CSV file operations
- Date and time handling

---

### 2. Streaming Platform Content Analysis

📁 Folder: `streaming-content-data-analysis/`

An exploratory data analysis (EDA) project that analyzes movies and TV shows data
from a streaming platform dataset sourced from Kaggle. The project focuses on
data cleaning, analysis, and visualization using Python libraries.

**Key Concepts Used:**
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Pandas and NumPy
- Data visualization with Matplotlib

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Purpose
These projects demonstrate my understanding of Python fundamentals, API usage,
file handling, and basic data analysis techniques through hands-on implementation.
