# Streaming Platform Content Analysis using Python

This project performs exploratory data analysis (EDA) on OTT streaming platform content using Python.
The goal is to analyze movies and TV shows data and extract meaningful insights using real-world data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter 

## Dataset
- Source: Kaggle
- Description: Dataset containing movies and TV shows available on a streaming platform (Netflix-based)
- Key columns: type, title, country, release_year, rating, duration

## Analysis Performed
- Loaded and inspected the dataset
- Handled missing values
- Analyzed Movies vs TV Shows distribution
- Studied content release trends over the years
- Identified top content-producing countries
- Analyzed most common content ratings
- Performed numerical analysis using NumPy
